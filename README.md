# Ecommerce-Sales-Data-Analysis
An end-to-end data analysis project using **Excel, MySQL, and Power BI** to analyze 10,000+ rows of sales data.

## 🛠️ Tech Stack
* **Excel:** Data generation
* **MySQL:** Database & SQL Queries
* **Power BI:** Interactive Dashboard

## 📊 Dashboard Features
* Live Total Revenue Tracking
* Product Category & State-wise Sales Analysis
* Dynamic Interactive Filters (Slicers)
